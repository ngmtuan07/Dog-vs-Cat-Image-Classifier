# Dog vs. Cat Image Classifier 🐶🐱

## Overview

This project implements a **binary image classifier** that can distinguish between images of **dogs and cats** using a **MobileNetV2** backbone. The model leverages **transfer learning** to quickly achieve high accuracy with limited training data.

It’s built using **TensorFlow/Keras** and is suitable for anyone learning **deep learning** and **computer vision**.

---

## Features

* Classifies images as **Dog** or **Cat**.
* Uses **MobileNetV2** pretrained on ImageNet for feature extraction.
* Lightweight and fast, suitable for smaller images (128×128).
* Supports GPU acceleration for faster training.
* Saves the trained model for inference.
